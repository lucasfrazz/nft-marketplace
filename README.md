# Kurio — NFT Marketplace (Frontend Challenge)

> 🚧 Em desenvolvimento. Documentação completa (setup, cenários, contratos, `ARCHITECTURE.md`) em breve.

Stack: React + TypeScript, TanStack Router, TanStack Query, Axios, Socket.IO, Tailwind CSS, shadcn/ui, MSW, Playwright, Lighthouse.

## Rodar localmente

```bash
npm install
npm run dev          # http://localhost:5173 (mocks MSW ativos via .env)
npm run build && npm run preview
npm run test:e2e     # Playwright
```
